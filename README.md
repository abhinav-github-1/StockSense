# StockSense

StockSense is a simple inventory, expiry, and reorder management platform for tracking products, stock movement, and alerts.

## Technology Stack

- Frontend: React with Vite
- Backend: Java Spring Boot
- Database: PostgreSQL
- API Style: REST
- Authentication: Spring Security + JWT
- ORM: Spring Data JPA
- Build Tool: Maven

## Planned Modules

- Authentication
- Users
- Products
- Categories
- Suppliers
- Inventory Transactions
- Dashboard
- Alerts
